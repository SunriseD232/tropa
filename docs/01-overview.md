# 01. Обзор проекта

## Зачем

Друзья владельца в России пользуются v2rayN и чужими подписками. v2rayN перегружен, непонятен и плохо объясняет, почему что-то не работает. Тропа — простой клиент, который:

- работает с VLESS, VMess и Trojan (позже Shadowsocks-2022, Hysteria2);
- хранит несколько подписок и серверов, тестирует их честно, сам выбирает рабочий;
- позволяет задавать правила для приложений и для сайтов, **отдельно для TCP и UDP**;
- использует два ядра (sing-box и Xray), не заставляя пользователя о них думать;
- у каждой настройки объясняет, что она делает и как помогает против блокировок (кнопка «i»);
- не даёт включить несовместимые опции и говорит почему.

## Пользователи

- **Друзья** — обычные пользователи Windows 10/11. Получают подписку от стороннего провайдера, хотят «нажал и работает», но доступ ко всем настройкам должен быть.
- **Владелец** — разбирается и помогает друзьям удалённо: экспорт правил файлом, отчёт диагностики.

Своего сервера и своей панели подписок нет: подписки сторонние (Marzban, 3x-ui, Remnawave и др.).

## Приоритеты (строго по порядку)

1. **Безопасность данных пользователя** — см. `02-security.md`.
2. **Обход блокировок** — устойчивость к ТСПУ.
3. Удобство, скорость, красота.

## Против чего работаем (ТСПУ, 2025–2026)

| Приём блокировки | Ответ Тропы |
|---|---|
| Блок по SNI | прокси; для прямого трафика — фрагментация ClientHello средствами ядра |
| Сигнатуры протоколов, TLS-in-TLS | VLESS + Reality + Vision, uTLS-отпечаток |
| Подмена DNS | удалённый DoH через туннель, FakeIP, перехват порта 53 |
| «Заморозка» TCP на ~16–20 КБ к IP хостингов | тест скорости это ловит, авто-выбор уводит, цепочки, XHTTP |
| Деградация QUIC/UDP | блок UDP/443, UDP через сервер |
| Белые списки мобильного интернета | цепочки через российские облака |
| Активное зондирование | Reality/Trojan с настоящим сайтом за спиной |

## Не делаем (сознательно)

- Не встраиваем zapret, GoodbyeDPI, WinDivert и любые сторонние драйверы/утилиты обхода.
- Не делаем свою серверную часть и панель подписок.
- Не собираем телеметрию.
- Не исполняем сторонние конфиги ядер как есть.
- Нет поддержки macOS/Linux на старте (Avalonia оставляет такую возможность).

## Название

«Тропа» — рабочее. Меняется в одном месте: `Tropa.App/Branding.cs` + ресурсы.
