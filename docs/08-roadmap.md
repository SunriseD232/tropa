**Ручная проверка TUN (нужны права администратора):**
1. `powershell -ExecutionPolicy Bypass -File tools/dev-install.ps1` из PowerShell «от имени администратора».
2. Запустить `C:\Program Files\Tropa\Tropa.exe`, добавить подписку, режим «Весь компьютер», «Подключить».
3. Проверить: сайты открываются; Discord-голос работает; правило «Discord.exe → через сервер» и «игра: UDP напрямую»; `nslookup discord.com` показывает адрес 198.18.x.x (FakeIP); https://ipleak.net не показывает DNS провайдера.
4. Убить `Tropa.exe` через диспетчер задач — интернет должен вернуться в обычный режим за пару секунд.
5. Удаление: `tools/dev-install.ps1 -Uninstall` — службы нет, `HKLM\SOFTWARE\Policies\Microsoft\Windows NT\DNSClient` как до установки.
