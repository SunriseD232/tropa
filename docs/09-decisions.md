# 09. Журнал решений (ADR)

Формат: номер, дата, решение, почему, последствия. Новые решения — в конец.

## ADR-001 · 2026-10-07 · Безопасность данных — приоритет №1
**Решение:** при конфликте «безопаснее» против «лучше обходит» выбираем безопасность. **Почему:** требование владельца. Друзья доверяют программе компьютер и данные. **Последствия:** `02-security.md` обязателен к исполнению, у каждого PR есть чек-лист.

## ADR-002 · 2026-10-07 · Без zapret, GoodbyeDPI, WinDivert
**Решение:** не встраивать и не запускать сторонние утилиты и драйверы обхода DPI. Приёмы (фрагментация, шум) реализуем только опциями ядер sing-box/Xray. **Почему:** риск вредоноса в обновлениях, драйвер ядра с полным доступом к трафику, риск потери данных. **Последствия:** фрагментация работает только для трафика, проходящего через ядро (режим TUN или прокси), а не для всей системы на уровне драйвера.

## ADR-003 · 2026-10-07 · Ядра тоже под контролем цепочки поставок
**Решение:** закреплённые версии и SHA-256, обновление только через наш подписанный Ed25519 манифест, проверка хэша перед каждым запуском. **Почему:** ядра — такой же сторонний код, как zapret. **Последствия:** новые версии ядер появляются у пользователей после проверки владельцем, а не сразу.

## ADR-004 · 2026-10-07 · Стек: .NET 10 + Avalonia 11
**Решение:** C#/.NET 10 LTS, Avalonia (11 → обновлено до 12, см. ADR-010), CommunityToolkit.Mvvm, xUnit, Inno Setup. **Почему:** нативная работа со службами Windows, DPAPI, WFP, реестром. Avalonia даёт современный UI, встроенный трей и возможность портирования. **Альтернативы:** WPF (только Windows, устаревший вид), Tauri (сложнее работа с привилегиями и службой).

## ADR-005 · 2026-10-07 · Разделение на App (пользователь) и Service (SYSTEM)
**Решение:** привилегированные операции — только в службе Windows. Интерфейс без прав администратора. Автозапуск интерфейса через HKCU Run. **Почему:** минимальная привилегированная поверхность, нет UAC при каждом входе. **Последствия:** тексты `autostart` в `info.ru.json` и в исходниках макета исправлены (2026-10-07); холст обновится при следующей публикации.

## ADR-006 · 2026-10-07 · Конфиг ядра генерирует App, служба его проверяет
**Решение:** генерация в App (там доступны секреты DPAPI CurrentUser), повторная проверка `ConfigGuard` в службе. **Почему:** секреты не хранятся под SYSTEM, а служба не доверяет клиенту.

## ADR-007 · 2026-10-07 · sing-box основное ядро, Xray по требованию
**Решение:** sing-box всегда фронт (TUN, DNS, правила по процессам). Xray запускается за SOCKS только для XHTTP и Xray-only функций. **Почему:** у sing-box лучше TUN и правила по процессам, у Xray новинки протокола. **Последствия:** UDP для гибридных профилей идёт через SOCKS5 UDP ASSOCIATE, его надо проверить интеграционными тестами.

## ADR-008 · 2026-10-07 · Сторонние конфиги не исполняются
**Решение:** из импортируемых JSON берём только outbound-ы. Пользовательский шаблон сливается по белому списку. **Почему:** чужой конфиг может писать файлы (`log.output`), открывать порты наружу, уводить трафик.

## ADR-009 · 2026-10-07 · Нет своей серверной части
**Решение:** клиент работает со сторонними подписками. Важна совместимость: User-Agent, HWID, разные форматы ответа. **Почему:** друзья используют чужие подписки.

## ADR-010 · 2026-10-07 · Актуальные версии на старте
**Решение:** Avalonia 12.1.3 (а не 11, как в первой версии ADR-004), CommunityToolkit.Mvvm 8.4.2, xUnit v3 3.2.2 (стабильная линия 3.x вместо свежей 4.0), Microsoft.Extensions.Hosting.WindowsServices 10.0.12. Ядра: sing-box 1.14.2, Xray 26.9.30. **Почему:** последние стабильные версии на дату старта. **Последствия:** примеры конфигов в `05-config-generation.md` писались для sing-box 1.12. Каждый блок генератора сверяется со схемой 1.14 и фиксируется golden-тестом.

## ADR-011 · 2026-10-07 · Лицензии ядер
**Решение:** sing-box — GPL-3.0-or-later, Xray — MPL-2.0. Распространяем их неизменёнными бинарниками отдельными процессами. В установщик кладём тексты лицензий и ссылки на исходники точных версий (тег из lock-файла). **Почему:** требования GPL/MPL при распространении бинарников. **Последствия:** своё приложение не линкуется с ядрами и общается с ними только через конфиги и процессы.

## ADR-012 · 2026-10-07 · CI закреплён по хэшам
**Решение:** GitHub Actions подключаются по SHA коммита (`actions/checkout` v7.0.1, `actions/setup-dotnet` v6.0.0), у токена только `contents: read`, restore в `--locked-mode`. **Почему:** тег action можно перевесить на вредоносный коммит. Это та же угроза цепочки поставок, что и с ядрами.
