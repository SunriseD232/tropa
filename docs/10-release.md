# 10. Выпуск и обновления

Как устроены обновления — ADR-023. Здесь — что делать руками.

## 1. Один раз: ключ подписи

Закрытый ключ подписи манифеста есть только у владельца. В репозиторий, CI и облака он не попадает.

```powershell
dotnet run --project tools/Tropa.Release -- keygen --out "$env:USERPROFILE\TropaKeys\manifest-signing.pem"
```

- Программа спросит пароль (не короче 12 символов). Ключ сохраняется зашифрованным (PKCS#8, AES-256, 600 000 итераций).
- Сделайте копию файла и пароля на флешку или в менеджер паролей. **Без ключа нельзя выпустить обновление**, а новый ключ старые копии Тропы не примут: тогда друзьям придётся вручную поставить новую версию.
- Напечатанный публичный ключ вставьте в `tools/update.config.json` → `publicKey`.
- `manifestUrl` уже указан: `https://github.com/SunriseD232/tropa/releases/latest/download/manifest.json`.
  Подпись лежит рядом: тот же адрес + `.sig`. **Выпуски должны быть доступны без входа в GitHub**
  (публичный репозиторий): иначе Тропа у друзей не сможет скачать ни манифест, ни установщик.

Пока `publicKey` или `manifestUrl` пустые, обновления в сборке выключены (карточка на главной так и пишет).

## 2. Выпуск

1. Поднять `Version` в `Directory.Build.props`.
2. Номер манифеста `N` = предыдущий + 1. Записать его в `tools/update.config.json` → `bundledSequence`
   (установщик с этим номером не будет брать более старые обновления).
3. Собрать локально: `powershell -ExecutionPolicy Bypass -File tools/build-release.ps1` (нужен Inno Setup 6).
   Или в GitHub: Actions → CI → Run workflow, указать тег — установщик и `SHA256SUMS.txt` попадут в **черновик**
   выпуска. Манифест подписывать для того установщика, который будет в выпуске (хэш входит в манифест).
4. Пройти ручной чек-лист (§4).
5. Создать выпуск на GitHub, приложить `Tropa-X.Y.Z-setup.exe`.
6. Манифест и подпись:
   ```powershell
   dotnet run --project tools/Tropa.Release -- manifest --sequence N --app-version X.Y.Z `
     --app-url https://github.com/<владелец>/<репозиторий>/releases/download/vX.Y.Z/Tropa-X.Y.Z-setup.exe `
     --installer out\Tropa-X.Y.Z-setup.exe --notes "Что нового" --out out\manifest.json
   dotnet run --project tools/Tropa.Release -- sign --key "$env:USERPROFILE\TropaKeys\manifest-signing.pem" --in out\manifest.json
   ```
   `sign` сразу проверяет подпись публичным ключом из `tools/update.config.json`.
7. Приложить к черновику выпуска `manifest.json` и `manifest.json.sig` и опубликовать его.
   Ссылку на установщик из выпуска можно передавать друзьям.

Только новые ядра или списки сайтов, без новой версии Тропы: обновить lock-файлы (`update-cores-lock.ps1`,
`update-geo-lock.ps1`), прогнать тесты, выпустить манифест с новым номером без `--app-version`.

Срок действия манифеста — 90 дней (`--expires-days`). Просроченный манифест Тропа не принимает
(защита от «заморозки»), поэтому раз в два-три месяца нужно выпускать манифест заново, даже без изменений.

## 3. Подпись кода (Authenticode)

Пока не подписываем (ADR-025, владелец согласен оставить так). Следствие: при запуске установщика,
скачанного браузером, Windows SmartScreen показывает «Windows защитила ваш компьютер» → «Подробнее» →
«Выполнить в любом случае». Это бывает при ручной установке (каждой новой версии, скачанной браузером);
обновления, которые Тропа скачивает сама кнопкой «Установить», браузерной пометки не имеют и обычно
предупреждения не вызывают. Друзьям это нужно объяснить один раз.
Целостность обновлений от этого не страдает: их проверяет подпись манифеста.

Варианты на будущее: SignPath Foundation (бесплатно для открытых проектов, нужен публичный репозиторий),
сертификат OV у удостоверяющего центра (платно, с аппаратным ключом), Azure Trusted Signing.

## 4. Ручной чек-лист перед выпуском

На чистой виртуальной машине Windows 10 22H2 и Windows 11 (без .NET):

- [ ] Установщик запускается, ставит службу «Тропа» (отложенный автозапуск), ярлыки в «Пуске».
- [ ] Галочка «Запускать вместе с Windows»: после перезагрузки Тропа в трее и подключается сама.
- [ ] Импорт подписки, тест серверов, подключение в обоих режимах.
- [ ] Режим «Весь компьютер»: сайты, Discord (голос), проверка DNS в диагностике.
- [ ] Kill switch: подключиться, убить `Tropa.exe` в диспетчере задач → интернета нет; запустить Тропу → плашка, «Снять блокировку» → интернет есть.
- [ ] Убить процесс службы → Windows перезапускает службу, блокировка снята (фильтры динамические).
- [ ] «Аварийно вернуть настройки сети» из «Пуска» при подключённой Тропе: прокси Windows и DNS вернулись.
- [ ] Режим «Только браузеры»: прокси Windows включён; после «Выход» — выключен.
- [ ] Обновление поверх предыдущей версии: настройки и подписки на месте, служба новая.
- [ ] Проверка обновлений на главной видит новый манифест; «Обновить» ставит ядра.
- [ ] Удаление: служба удалена, прокси Windows выключен, `%ProgramData%\Tropa` и `Program Files\Tropa` удалены;
      на вопрос «Удалить настройки?» — «Нет» → `%APPDATA%\Tropa` остался, «Да» → удалён.
- [ ] `netsh wfp show filters` после удаления: фильтров Тропы нет.
