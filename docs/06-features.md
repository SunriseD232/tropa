# 06. Экраны и функции

Источник правды по виду — макеты (`design/canvas-src/`, холст в `CLAUDE.md`). Здесь — что каждая функция обязана делать. Тексты справки — `docs/info.ru.json` (ключ указан в скобках).

## Общие механики интерфейса

- **Кнопка «i»** у каждой настройки, заголовка столбца, шага диагностики и правила. Открывает модальное окно: «Что это», «Зачем нужно», «Как помогает против блокировок» (зелёный блок), «Подводные камни», «Совместимость» (синий блок). Если пункт сейчас недоступен, сверху жёлтая строка «Сейчас недоступно: <причина>». Закрывается по крестику, кнопке «Понятно», клику по фону и Esc.
- **Несовместимости:** пункт, заблокированный правилом из `CompatRules`, неактивен, под ним жёлтым причина. Сохранённое значение пользователя возвращается, когда блокировка снимается.
- **Ctrl+V в любом месте окна:** если в буфере ссылка или URL подписки — открывается окно импорта с подставленным значением.
- Тёмная тема по умолчанию, светлая и «как в Windows». Минимальная ширина окна 900 px, при узком окне боковое меню сворачивается в иконки.
- Доступность: всё управляется с клавиатуры, у иконочных кнопок есть подписи для экранного диктора.

## 0. Первый запуск
Шаг 1 — вставить ссылку подписки (или ссылки vless://, QR, файл). Шаг 2 — режим «Весь компьютер» / «Только браузеры» и галочка «Запускать вместе с Windows и сразу подключаться». Кнопка «Подключиться» → тест серверов → подключение к лучшему.

## 1. Главная
- Большая кнопка подключения: состояния «Отключено / Подключение… / Подключено / Ошибка (с причиной)», время сеанса.
- Текущий сервер (страна, имя, протокол/транспорт/безопасность/ядро, задержка) и кнопка «Сменить» (быстрый список).
- Переключатель «TUN — весь компьютер» (`tunSwitch`, ADR-056): включён — Тропа работает для всего компьютера; выключен — выключена, если в «Системном прокси» не выбрано «Установить». Большая кнопка подключения остаётся и синхронна с ним.
- «Системный прокси» (`sysProxyMode`, ADR-056): «Установить / Очистить / Не менять системный прокси», как в v2rayN; действует при выключенном TUN, применяется сразу.
- Маршрут: `except_ru` / `blocked` / `all` (`route`), под ним пояснение выбранного варианта. Меняется сразу: при подключении Тропа переподключается сама (ADR-056).
- Трафик: скорость вниз/вверх, итог за сеанс, мини-график за 60 с.
- «Сейчас через сервер»: процессы с активными соединениями и пометками TCP/UDP (только в TUN, иначе пояснение).
- Проверки: последние результаты (DNS через туннель, UDP, IPv6) и ссылка в «Диагностику».
- Плашка подписки: остаток трафика и срок, предупреждение за 3 дня.

## 2. Серверы
- Вкладки по подпискам и «Мои». Таблица: флаг страны выхода по последней проверке (ADR-042; «–» — не проверялся или не ответил), имя, протокол, транспорт, задержка, скорость, статус (`status`). Сортировка, поиск, избранное.
- Кнопки «Обновить подписки», «Тест всех», «Добавить». Авто-выбора сервера нет (ADR-047).
- На вкладке подписки от администратора — пояснение и кнопка «Доверять администратору» / «Не доверять администратору» (ADR-048).
- Панель выбранного сервера: последний тест (TCP-пинг, реальная задержка, скорость, UDP, стабильность), параметры (секреты скрыты), кнопки «Тест», «Изменить», «QR / ссылка».
- Статусы: Работает / Медленно / Данные не идут (заморозка) / Нет ответа / Несовместимые параметры / allowInsecure (красный).

## 3. Правила
- Основа (пресет), импорт и экспорт правил файлом (`ruleExport`).
- Быстрые переключатели: `blockQuic`, `udpProxy`, `fragment`.
- Таблица «Приложения»: процесс (выбор из запущенных или exe-файла), действие TCP, действие UDP, вкл/выкл, перетаскивание. Пометка «только в режиме Весь компьютер».
- Таблица «Сайты и IP»: домен, суффикс, ключевое слово, regex, geosite, geoip, CIDR, свой список; действия TCP/UDP. Финальное правило задаётся пресетом.
- Карточка «Гео-базы» (`geoLists`, ADR-039): девять закреплённых наборов (IP-адреса и сайты), у каждого — «Открыть» и плашка с числом правок. Окно набора: поиск по всему списку, вид «Весь список / Добавленные мной / Убранные мной», проверка адреса («Проверить»: попадает ли сайт или IP в список с учётом несохранённых правок и какая запись сработала; для IP-списка сайт по нажатию разрешается системным DNS, условные адреса FakeIP распознаются), «Добавить…» — отдельное окно: вид записи (для сайтов — домен и поддомены, только этот адрес, содержит слово, регулярное выражение RE2; для IP — адрес или сеть) с правилом и примером, несколько записей с новой строки; × убирает запись, ↶ возвращает убранную, «Сбросить мои правки», «Сохранить» / «Отмена». Списки до ~90 тыс. записей показываются виртуализированным списком.
- «Свои списки» (ADR-040) в карточке «Гео-базы»: «Создать список» — название, действие (через сервер / напрямую / блокировать), вкл/выкл, записи всех видов; окно то же, что у гео-баз. В «Добавить…» вид «Список из v2ray / Clash»: префиксы domain:/full:/keyword:/regexp:, IP и сети, без префикса — домен и поддомены.
- Поле «Проверить адрес»: показывает сработавшее правило и итоговое действие (вычисляется в `Tropa.Core`, без сети).

## 4. Диагностика
Шаги, кнопка «Проверить всё заново», отчёт («Скопировать», «Сохранить файл»), журнал с фильтром. Алгоритмы — `07-testing-diagnostics.md`.

## 6. Окна
- **Добавить серверы:** вкладки «Подписка по URL», «Вставить ссылки», «QR-код» (с экрана / из картинки), «Файл». Предпросмотр: найдено N, ошибки построчно, остаток и срок подписки, предупреждения (без шифрования, allowInsecure, несовместимые параметры).
- **Редактирование сервера:** поля по протоколу, транспорту и безопасности. Варианты, несовместимые с текущим выбором, неактивны с причиной. Ссылка собирается на лету. Ядро показывается автоматически.

## 6а. Вид «как в v2rayN» (ADR-051)
Меню «Серверы / Подписки / Настройки / Справка», вкладки подписок и поиск, таблица серверов (тип, имя, адрес, порт, транспорт, TLS, подписка, задержка, скорость, страна выхода, статус; щелчок по заголовку — сортировка показа ↑ / ↓ / свой порядок), журнал внизу с фильтром, строка состояния: порт, TUN, маршрут, сервер, скорость, «Подключить». Ctrl+E — проверить все, Enter / двойной щелчок — активный, Delete — удалить. Параметры, правила, диагностика — на месте таблицы, «← Серверы» — назад. Сверка с v2rayN — `docs/11-v2rayn-gap.md`.

## 6в. Строка состояния вида «как в v2rayN» (ADR-056)
«Включить TUN» (включает и выключает Тропу, кнопки «Подключить» нет), «Маршрут», «Системный прокси» — у каждого «i»; справа — состояние, сервер, скорость, страна выхода. Локального порта в строке нет. В предупреждении при запуске у Тропы без прав — кнопка «Перезапустить от имени администратора».

## 6б. Действия со списком серверов (как в v2rayN)
- Выделение нескольких: Ctrl/Shift + щелчок, Ctrl+A. «Удалить» и «Проверить» действуют на все выделенные. Удаление серверов (одного, нескольких, дубликатов, нерабочих) — без подтверждения, по решению владельца: свои стираются, из подписки — скрываются («Вернуть удалённые»). Подтверждение осталось только у удаления подписки и выгрузки конфига с ключами.
- Фильтры (оба вида окна): название или адрес, протокол, скорость по последней проверке (от 5/20/50/100 Мбит/с или «проверенные и рабочие»), страна выхода (из последних проверок); «Сбросить фильтры».
- «Создать копию» — копия в «Мои» сразу под исходным.
- «Удалить дубликаты» — совпадает всё, кроме названия (ссылка без «#имени» и цепочка); остаётся выбранный, иначе верхний.
- «Удалить нерабочие» — по последней проверке: нет ответа, ошибка рукопожатия, «данные не идут»; выбранный не трогается.
- «Скопировать ссылку», «Показать QR-код» (окно с кодом и кнопкой «Скопировать ссылку») — буфер очищается через 60 с (ADR-053).
- «Выгрузить полный конфиг (с ключами)…» — предупреждение, затем файл через диалог: конфиг sing-box или Xray для одного сервера, вход — локальный порт с паролем (ADR-054).
- «Добавить серверы»: «QR с экрана» (окно сворачивается, снимок только в памяти) и «QR из картинки…» (до 30 МБ) — найденное подставляется в поле (ADR-053).
- «Настройки → Общие → Права администратора»: «Перезапустить от имени администратора»; в заголовке окна — «Тропа — администратор» или «Тропа — обычный пользователь» (ADR-052).

## 7. Трей
Статус, «Подключить/Отключить» (горячая клавиша), подменю «Сервер», «Режим», «Маршрут», «Тест серверов», «Обновить подписки», «Открыть», **«Аварийно вернуть настройки сети»**, «Выход».

## 8. Уведомления
Смена сервера администратором подписки, падение ядра, окончание подписки через 3 дня, доступно обновление, все серверы недоступны.
